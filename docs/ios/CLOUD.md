# Codex Cloud 연결 및 작업 재개

저장소 준비와 Codex Cloud 환경 게시/실행은 별개입니다.
이 문서는 환경이 이미 생성되었다는 증거가 아닙니다.

환경 구성:
- 저장소: ajellia81-cmd/segarally95-recomp만 연결
- 시작 브랜치: ios-port
- 플랫폼: C 컴파일러, CMake 3.20 이상, Python 3가 있는 Linux 이미지
- 준비 명령: bash .codex/setup.sh
- 유지보수: 동일한 명령으로 컴파일 검증
- ROM, 게임 실행, ROM 추출, optional tools 저장소 복제: 사용하지 않음
- 서명 인증서/Apple 계정/기기 자산: 환경에 추가하지 않음

OpenAI의 설정 > Codex Cloud > Environments에서 환경을 생성/선택하고,
위 포크와 준비 명령을 지정한 뒤 준비 결과를 검토하여 게시합니다.
게시된 환경에서 단계 2 작업을 실제로 시작해야 PC가 꺼진 동안에도 해당 작업이 진행됩니다.
환경만 생성하거나 이 문서를 커밋하는 것은 백그라운드 작업 시작이 아닙니다.

환경 ID, 게시 성공, 실제 작업 링크는 UI에서 확인된 경우에만 기록합니다.
현재 이 변경에는 확인된 환경 ID/실행 링크가 없습니다.
