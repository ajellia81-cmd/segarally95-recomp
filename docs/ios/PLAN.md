# 개인용 iPhone/iOS 이식 단계

대상은 개인 포크 `ajellia81-cmd/segarally95-recomp`의 `ios-port`입니다.
원래 main 기준은 `6fe9db1a276996f1893e9e94d50617e49580688c`입니다.
upstream 수정과 ROM의 git/CI/IPA 포함·배포는 범위에서 제외합니다.
후속 사용자 요청에 따라 제공된 B ZIP의 개인용 로컬 변환 검증을 별도 scratch에서 수행했고,
앱이 기기 안에서 ZIP을 준비하도록 구현했습니다. 인터넷에서 ROM을 취득하지 않았습니다.

| 단계 | 구현 상태 | 검증 범위 |
|---|---|---|
| 클라우드 준비 | 포크 브랜치, 게시된 환경, 재사용 스크립트 | 설정 게시 확인, ROM 없는 Linux 컴파일 |
| 코어 경계 | 오류 반환 초기화, 명시적 로딩, begin/step 경계 | 가짜 서비스로 순서·halt 테스트 |
| 네이티브 앱 | UIKit + 정적 코어 링크, 단일 백그라운드 소유자 | Apple SDK 컴파일·링크, 합성 화면으로 시뮬레이터 설치·실행 |
| Metal | 기존 타일·GEO·텍스처·팔레트·깊이/스텐실 경로 연결 | 셰이더 컴파일, ROM 없는 합성 단색·텍스처 및 edge-clamp 픽셀 검사 |
| iOS 서비스 | 오디오 PCM, 중단/복귀, 입력 해제, 원자적 저장 | API 컴파일, 가짜 SRAM 저장·복원 테스트 |
| 입력 | 터치 및 GCController, 여러 입력의 조향/기어 조정 | 정규화 범위·NaN·해제 테스트; 실제 기기 조작 미검증 |
| ZIP 준비 | B 합본 srallyc.zip 선택/CRC 검증/기기 내 BIN 생성 | 합성 ZIP host 테스트, 사용자 제공 B ZIP의 개인 변환 결과 일치 |
| 와이드/앱 표시 | 실제 drawable 비율로 가로 투영 확대, 전체 화면, 이름/아이콘 0.2 | host 비례 검사, SDK 컴파일, 패키지 아이콘/이름 확인; 실제 게임 외곽 표시 미검증 |
| IPA 생성 | arm64 Release 미서명 IPA, 개인 bundle ID | 최신 CI 및 다운로드 파일 검사는 IPA_BUILD.md 참조 |
| 개인 기기 확인 | 아직 수행하지 않음 | 서명·설치·게임 재생·음향·성능 확인 필요 |

실행 흐름은 기존 cold boot와 game_dispatch_main을 유지합니다. UIKit 메인 스레드에서
게임 루프를 실행하지 않습니다. 기존 GEO 명령/게임 카메라는 유지하며, 사용자가 요청한
와이드를 위해 호스트 투영 창만 가로로 넓힙니다. 게임 타이밍은 변경하지 않습니다.
터치는 extendedGamepad 연결 때 숨기고 분리 때 복원합니다. 진동/햅틱은 넣지 않습니다.

초기 요청의 정지 지점은 IPA 생성 전이었습니다. 2026-10-22 사용자가 개인용 미서명 IPA
생성을 추가 승인했으며, 최신 패키지/검증 상태는 IPA_BUILD.md에 기록합니다.
Apple 서명이나 공개 Release는 수행하지 않습니다.
실제 게임·기기 검증을 하지 않은 부분은 완료/지원/성능으로 주장하지 않습니다.
구체적인 준비 명령 및 남은 확인은 READY.md와 platform/ios/README.md를 참조하세요.
